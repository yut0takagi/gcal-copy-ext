# GCal 予定コピー

Google カレンダーの予定ポップアップに「予定をコピー」ボタンを追加する Chrome 拡張機能です。
ボタンを押すと、予定の情報を決まった書式のテキストにしてクリップボードへコピーします。
チャットやメールに予定を貼り付けるときの手間を省けます。

## コピーされる内容

```text
---------------------------------------------------------------------------------------------------
[ タイトル ]: 定例ミーティング
[ 期間 ]: 2026/10/01(木) 10:30 - 11:30
[ 参加者 ]: 山田太郎,佐藤花子
[ 場所 ]: 会議室A
[ ※Meet URL ]: https://meet.google.com/abc-defg-hij
[ 説明 ]: 今週の進捗確認
[ スケジュールURL ]: https://www.google.com/calendar/event?eid=xxxxxxxx
---------------------------------------------------------------------------------------------------
```

- 期間は「午前/午後」を 24 時間表記に直します。時刻のない予定は「終日」になります
- Meet URL はクエリ文字列を除いた会議 URL だけを残します
- 予定に入っていない項目は空欄のまま出力します

## インストール

Chrome ウェブストアには公開していません。ソースから読み込んで使います。

1. このリポジトリを clone するか、ZIP でダウンロードして展開する
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパー モード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」を押し、このフォルダを選ぶ

Edge など Chromium 系のブラウザでも同じ手順で読み込めます。

## 使い方

1. [Google カレンダー](https://calendar.google.com/) で予定をクリックし、ポップアップを開く
2. ポップアップ上部の「メールで送信」ボタンの右隣に出るコピーボタンを押す
3. アイコンがチェックマークに変わればコピー完了。あとは貼り付けるだけです

ヘッダーのボタンが見つからないときは、ポップアップ下部に「📋 コピー」ボタンが出ます。
新しい予定を作るときのクイック作成画面には、ボタンを出しません。

## 注意点

- Google カレンダーを日本語表示で使う前提です。ほかの言語では、期間がうまく整形されないことがあります
- Google カレンダーの画面構成をもとにボタンの位置や予定の情報を読み取っています。Google 側の画面が変わると動かなくなることがあります
- 予定の情報はクリップボードへ書き込むだけで、外部には送信しません。動作するのは `https://calendar.google.com/calendar/*` のページだけです。詳しくは[プライバシーポリシー](PRIVACY.md)を参照してください
- Google が提供・承認している拡張機能ではありません
